## Implementation Steps
1. Add `builder.Services.AddAuthentication(JwtBearerDefaults.AuthenticationScheme).AddJwtBearer(...)` with `TokenValidationParameters` reading from `JwtSettings__SecretKey`
2. Add CORS: `builder.Services.AddCors(...)` allowing frontend origin from env `CORS_ALLOWED_ORIGINS`
3. Add rate-limiting: `builder.Services.AddRateLimiter(...)` with fixed-window policy (10 req/min per IP) applied to `/api/v1/auth/login`
4. Configure MSAL: `AzureAd__TenantId`, `AzureAd__ClientId`, `AzureAd__ClientSecret`
5. Register DI: IAuthService→AuthService, ITokenService→TokenService, IAccountService→AccountService
6. Ensure `app.UseAuthentication(); app.UseAuthorization();` in correct middleware order
