## Key Functions/Methods
| Name | Signature | Responsibility |
|------|-----------|----------------|
| CompOffRequestService.SubmitRequest | `Task<Result>` | Validate hours >= 4; worked_date must be holiday; UNIQUE check |
| CompOffCreditService.CreditBalance | `Task CreditBalance(Guid requestId)` | Compute days (4h=0.5d, 8h=1d); create comp_off_credits row; call LeaveBalanceService.DeductBalance to add to comp-off balance type |

## Implementation Steps
1. SubmitRequest: check worked_hours >= 4 (422 if not); check HolidayService.IsHoliday(worked_date) (422 if not); check UNIQUE; create request
2. ApproveRequest: call CreditBalance; notify employee; log audit
3. CreditBalance: credit_days = worked_hours >= 8 ? 1.0m : 0.5m; expires_at = worked_date + 180 days; call LeaveBalanceService to increment comp-off leave balance
4. CompOffExpiryJob: daily; find comp_off_credits where expires_at < today AND used_days < credit_days; mark as expired
