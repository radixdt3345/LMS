| DELETE | /api/v1/holidays/{id} | HRAdmin+ | 204 |

## Key Functions/Methods
| Name | Signature | Responsibility |
|------|-----------|----------------|
| HolidayService.BulkImport | `Task<BulkImportResultDto> BulkImport(IFormFile csv)` | Parse CSV; validate each row; skip duplicates; insert valid rows |
| HolidayService.IsHoliday | `bool IsHoliday(DateOnly date)` | Check cached holiday set |

## Implementation Steps
1. Create `HolidayService`; cache holiday list as `HashSet<DateOnly>` in IMemoryCache (key "holidays_{year}", 1h TTL)
2. BulkImport: read CSV with CsvHelper or manual parsing; validate date format (YYYY-MM-DD); skip if date already exists (add to skipped list); insert valid rows
3. IsHoliday: load cached HashSet; O(1) lookup — no DB round-trip
4. Cache invalidated on Create, BulkImport, Delete
