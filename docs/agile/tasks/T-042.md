## Sandwich Rule Algorithm
The sandwich rule applies ONLY to a single request's date range:
1. For each day D in [start_date .. end_date]:
   - If D is a weekday AND not a holiday → count as leave day
   - If D is a weekend or holiday AND the preceding AND following days within the SAME range are leave days → count as leave day (sandwiched)
2. Non-working days before start_date or after end_date of THIS request are NEVER counted.
3. Non-working days between two SEPARATE requests are NEVER counted (UT-38).

## Implementation Steps
1. Create `SandwichRuleEngine` in `LMS.Domain/Services/`; inject cached holiday HashSet from IMemoryCache
2. Implement ComputeLeaveDays: iterate dates; for non-working days check if bounded by working days within the SAME request range
3. `SubmitRequest`: call ComputeLeaveDays; check balance (skip Unpaid); check overlapping requests (same employee, overlapping date range, status in Pending/Approved); set is_retroactive; save computed_days; create initial approval_step(s) via ApprovalService routing
4. `CancelRequest`: validate caller is owner; validate status; restore balance; log audit
5. `RevokeRequest`: HR Admin only; restore balance; enqueue CalendarService.DeleteLeaveEvent; create notification; log audit
