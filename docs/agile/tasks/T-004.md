### API Endpoints

### Key Functions/Methods
| Name | Signature | Responsibility |
|------|-----------|----------------|
| TokenService.ValidateRefreshToken | `Task<Result<User>> ValidateRefreshToken(string token)` | Hash token, find in DB, check expiry + not revoked |
| TokenService.RevokeRefreshToken | `Task RevokeRefreshToken(string token)` | Set revoked_at = now |

## Implementation Steps
1. `ValidateRefreshToken`: SHA256 hash input; find refresh_token row; check expires_at > now AND revoked_at IS NULL; load User
2. `RevokeRefreshToken`: find by hash; set revoked_at = now; save
3. POST /auth/refresh: validate → revoke old token → issue new access + refresh token (rotation)
4. POST /auth/logout: revoke current refresh token; return 204
5. GET /auth/me: read claims from JWT; query user by user_id claim; return profile DTO
