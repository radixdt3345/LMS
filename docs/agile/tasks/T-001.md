| Table | Operation | Fields |
|-------|-----------|--------|
| users | CREATE | id uuid PK, email varchar(256) UNIQUE NOT NULL, password_hash varchar(512), azure_ad_oid varchar(128) UNIQUE, role smallint NOT NULL DEFAULT 0, department_id uuid FK nullable, is_active bool DEFAULT true, failed_login_count smallint DEFAULT 0, lockout_until timestamptz NULL, created_at timestamptz NOT NULL, updated_at timestamptz NOT NULL |

## Implementation Steps
1. Create `LMS.Domain/Enums/UserRole.cs` with 4 values (Employee=0, Manager=1, HRAdmin=2, SuperAdmin=3)
2. Create `LMS.Domain/Entities/User.cs` — all columns as C# properties; use `Guid` for id; `UserRole` enum for role
3. Create `LMS.Domain/Entities/RefreshToken.cs` — FK property `UserId Guid`, navigation `User User`
4. Register both DbSets in `LmsDbContext.cs`
5. Create `UserConfiguration.cs`: apply snake_case naming, set UNIQUE indexes on email + azure_ad_oid, configure `lockout_until` as nullable `DateTime?` mapped to `timestamptz`
6. Create `RefreshTokenConfiguration.cs`: FK to users with cascade delete; index on token_hash
7. Run `dotnet ef migrations add CreateUsersAndRefreshTokens -p LMS.Infrastructure -s LMS.API`
8. Review generated migration SQL — verify snake_case, UUID PKs, timestamptz columns
9. Run `dotnet ef database update` against `lms_test` DB to verify
