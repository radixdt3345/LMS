## Key Functions/Methods
| Name | Signature | Responsibility |
|------|-----------|----------------|
| EmployeeService.DeriveRole | `Task DeriveRole(Guid userId)` | If user has any is_active direct reports → role=Manager; else no change |
| EmployeeService.CreateEmployee | `Task<Result<EmployeeDto>> CreateEmployee(CreateEmployeeDto dto)` | Create user, run DeriveRole on manager_id target, wire AuditService |
| EmployeeService.DeactivateEmployee | `Task<Result> DeactivateEmployee(Guid id)` | Set is_active=false; block future login |

## Implementation Steps
1. Create `EmployeeService` with all CRUD methods
2. `DeriveRole`: idempotent — query DirectReports where is_active=true; if count > 0 set role=Manager; if already Manager do nothing
3. On CreateEmployee: set employee_code, call DeriveRole on manager if manager_id provided; call AuditService.LogAsync
4. On UpdateEmployee: if manager_id changed, call DeriveRole on old and new manager; call AuditService.LogAsync
5. On DeactivateEmployee: set is_active=false; call AuditService.LogAsync
6. GetTeam: return direct reports (manager_id = calling user's id) — enforce calling user IS the manager (or HR Admin)
7. PUT /employees/me: only allow first_name, last_name, phone fields; ignore role, department_id, employee_code
