## Approval Routing Logic (CRITICAL — HIL-confirmed)
```
IF employee.manager_id IS NULL:
  → Create 1 approval_step (step_number=1, approver=HR Admin)
  → L2 UNCONDITIONALLY SKIPPED (even if is_retroactive=true)
  → Final: HR Admin approves step 1 → status=Approved

IF employee.manager_id IS NOT NULL:
  → Create step 1: approver=Manager
  → IF (is_retroactive=true OR leave_type.requires_l2=true):
      Create step 2: approver=HR Admin
  → ELSE: single step, Manager approval = final

Final approval (last step) triggers:
  → LeaveBalanceService.DeductBalance
  → NotificationService.CreateNotification (employee)
  → Hangfire.Enqueue(EmailService.SendEmailAsync)
  → Hangfire.Enqueue(CalendarService.CreateLeaveEvent) [on approve only]
  → AuditService.LogAsync
```

## Key Functions/Methods
| Name | Signature | Responsibility |
|------|-----------|----------------|
| ApprovalService.RouteRequest | `Task RouteRequest(LeaveRequest req)` | Create approval_step rows per routing logic above |
| ApprovalService.ApproveL1 | `Task<Result> ApproveL1(Guid requestId, Guid approverId)` | Mark step 1 approved; if no step 2 → finalize |
| ApprovalService.ApproveL2 | `Task<Result> ApproveL2(Guid requestId, Guid approverId)` | Mark step 2 approved → finalize |
| ApprovalService.RejectRequest | `Task<Result> RejectRequest(Guid requestId, Guid approverId, string comment)` | Mark step rejected; status=Rejected; notify; no balance change |

## Implementation Steps
1. Create `ApprovalService` with all 4 methods
2. `RouteRequest` called from `LeaveRequestService.SubmitRequest` — creates approval_steps in DB immediately on submit
3. `ApproveL1`: find step 1; verify caller IS the assigned approver (or HRAdmin for no-manager case); mark Approved; check if step 2 exists → if no step 2, finalize; if step 2, notify HR Admin
4. `ApproveL2`: find step 2; verify caller is HRAdmin; mark Approved; finalize
5. Finalize: call DeductBalance; create notification; enqueue email + calendar; log audit
6. `RejectRequest`: mark current pending step as Rejected; set leave_request.status=Rejected; notify employee; no balance change
