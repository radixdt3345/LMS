## Key Functions/Methods
| Name | Signature | Responsibility |
|------|-----------|----------------|
| LeaveBalanceService.GetBalance | `Task<List<BalanceDto>> GetBalance(Guid userId, int year)` | Return balances per leave type |
| LeaveBalanceService.DeductBalance | `Task<Result> DeductBalance(Guid userId, Guid leaveTypeId, decimal days)` | Subtract from allocated; reject if insufficient (except Unpaid) |
| LeaveBalanceService.RestoreBalance | `Task RestoreBalance(Guid userId, Guid leaveTypeId, decimal days)` | Add back to used_days |
| LeaveBalanceService.CreditAnnual | `Task CreditAnnual(int year)` | Credit all active employees for new year |
| LeaveBalanceService.ProrateForNewJoiner | `Task ProrateForNewJoiner(Guid userId, DateTime joinDate)` | (remaining_months/12) × annual_entitlement |
| LeaveBalanceService.YearEndLapse | `Task YearEndLapse(int year)` | Zero non-carry-forward balances |

## Hangfire Jobs (recurring)
| Job | Cron | IST equivalent |
|-----|------|----------------|
| NewYearCreditJob | `30 18 31 12 *` | 31 Dec 18:30 UTC = 01 Jan 00:00 IST |
| YearEndLapseJob | `0 18 31 12 *` | 31 Dec 18:00 UTC = 31 Dec 23:30 IST |
| CompOffExpiryJob | `30 18 * * *` | Daily 18:30 UTC = 00:00 IST |

## Implementation Steps
1. Create `LeaveBalanceService` with all 6 methods; Unpaid Leave bypass: check leave_type.accrual_type == Unlimited → skip balance check in DeductBalance
2. ProrateForNewJoiner: `remainingMonths = 12 - joinDate.Month + 1`; credit = Round(remainingMonths / 12.0 * annual_entitlement, 1, MidpointRounding.ToEven)
3. Create Hangfire job classes: `NewYearCreditJob`, `YearEndLapseJob`, `CompOffExpiryJob`; register with RecurringJob.AddOrUpdate in Program.cs
4. API endpoints: GET /api/v1/leave-balances/me, GET /api/v1/leave-balances/{userId} (HRAdmin+)
