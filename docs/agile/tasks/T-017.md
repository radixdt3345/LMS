## Implementation Steps
1. Create `DepartmentService` with CRUD methods; inject IMemoryCache; cache GET list with key "departments_active" (1h TTL)
2. Invalidate cache in Create, Update, Deactivate via `_cache.Remove("departments_active")`
3. Soft-delete: check `users.department_id == id AND is_active=true`; return 409 if any
4. Wire RBAC: `[Authorize(Policy="HRAdminOrAbove")]` on write endpoints; GET is `[Authorize]` (any role)
