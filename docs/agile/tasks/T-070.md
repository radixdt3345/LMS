## Key Functions/Methods
| Name | Signature | Responsibility |
|------|-----------|----------------|
| ReportService.GetUtilization | `Task<UtilizationDto> GetUtilization(int year, Guid? deptId)` | Sum used_days/allocated_days per dept |
| ReportService.GetTrends | `Task<TrendsDto> GetTrends(int months)` | Monthly leave count by type |
| ReportService.GetCompliance | `Task<ComplianceDto> GetCompliance()` | % employees with at least 1 Approved leave plan submitted |
| ReportService.ExportCsv | `IAsyncEnumerable<string> ExportCsv(string type)` | Streaming CSV — never load full dataset into memory |

## RBAC
Each dashboard endpoint returns 403 for wrong role (enforced via Policy attribute per endpoint).

## Implementation Steps
1. Create `ReportService` in Application layer
2. GetUtilization: join leave_balances + users (by dept); aggregate used_days / allocated_days
3. ExportCsv: use `IAsyncEnumerable` + `yield return` for streaming; set `Response.ContentType = "text/csv"`; do NOT `await ToListAsync()` — use `AsAsyncEnumerable()`
4. Dashboard endpoints: each calls appropriate ReportService + other services; enforce role via `[Authorize(Policy="...")]`
5. super-admin dashboard: call Hangfire monitoring API (`IMonitoringApi`) for job stats
