## Key Functions/Methods
| Name | Signature | Responsibility |
|------|-----------|----------------|
| AuditService.LogAsync | `Task LogAsync(string action, string entityType, Guid entityId, Guid actorId, object? oldValue, object? newValue)` | INSERT only; serialize old/new to jsonb |
| AuditService.Delete | `never exists` | Throws InvalidOperationException if called (UT-56) |

## Implementation Steps
1. Create `AuditService` in Application layer; `IAuditService` interface
2. `LogAsync`: serialize oldValue + newValue to JSON; INSERT into audit_logs; never throws (swallow exception + log)
3. Guard: `void Delete(...)` method explicitly throws `InvalidOperationException("Audit logs are immutable")`
4. Wire AuditService.LogAsync calls into: EmployeeService (Create, Update, Deactivate), DepartmentService (Create, Update, Delete), LeaveRequestService (Submit, Cancel, Revoke), CompOffRequestService (Approve, Reject), ApprovalService (Approve, Reject), AccountService (Lock, Unlock)
5. GET /audit-logs: filter by entity_type, entity_id, date range; paginate; HRAdmin+ only
