## Implementation Steps
1. Create `ITokenService` and `TokenService`: `IssueAccessToken` builds JWT (claims: user_id, role, department_id, jti; exp=15min); `IssueRefreshToken` generates 32-byte random token, stores SHA256 hash in refresh_tokens (expires 7 days)
2. Create `IAuthService` and `AuthService.LoginAsync`: find user by email; if not found return generic 401; check is_active; check lockout_until > now → return 423; verify BCrypt password hash; on failure: increment failed_login_count, if count >= 5 set lockout_until = now + 30min, return 401/423; on success: reset count, issue tokens
3. Create `LoginRequestDto` with FluentValidation: email required + valid format, password required non-empty
4. Create `AuthController` with `[HttpPost("login")]`; call AuthService.LoginAsync; map Result to HTTP response (200/401/423)
5. Register IAuthService, ITokenService in DI (Program.cs)
6. Add JWT config: `JwtSettings__SecretKey`, `JwtSettings__Issuer`, `JwtSettings__Audience` from env
