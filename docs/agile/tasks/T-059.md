# T-059 — NOTIFICATIONS-API-001: NotificationService + EmailService (SendGrid) + CalendarService

## Type
Development

## Issue Reference
Issue ID: NOTIFICATIONS-API-001 | Feature: F-12 | Epic: E-12

## CRITICAL CONSTRAINTS
- SendGrid: plain-text/inline-HTML body built in C# string. NO template IDs. NO dynamic template API. NO `templateId` property anywhere.
- Google Calendar: service account JSON key from env `GOOGLE_CALENDAR_SERVICE_ACCOUNT_JSON`. NO per-user OAuth2. NO consent redirect.

## Key Functions/Methods
| Name | Signature | Responsibility |
|------|-----------|----------------|
| NotificationService.CreateNotification | `Task CreateNotification(Guid userId, string title, string body, string? resourceType, Guid? resourceId)` | Insert notification row |
| NotificationService.GetUnreadCount | `Task<int> GetUnreadCount(Guid userId)` | COUNT where is_read=false |
| NotificationService.MarkRead | `Task MarkRead(Guid notificationId, Guid userId)` | Set is_read=true |

| CalendarService.DeleteLeaveEvent | `Task DeleteLeaveEvent(string eventId)` | Delete event by ID |

## Implementation Steps
1. Create `NotificationService` in Application layer; inject DbContext
2. Create `EmailService` in Infrastructure layer:
   - Use `SendGrid.SendGridClient(apiKey)` 
   - Build `SendGridMessage` with `SetFrom`, `AddTo`, `SetSubject`, `AddContent(MimeType.Text, textBody)`, `AddContent(MimeType.Html, htmlBody)`
   - NO `msg.SetTemplateId(...)` — this is forbidden
   - `SendEmailAsync` returns Task (fire-and-forget via Hangfire)
3. Create `CalendarService` in Infrastructure layer:
   - Load service account JSON from env `GOOGLE_CALENDAR_SERVICE_ACCOUNT_JSON` (JSON string, not file path)
   - Use `GoogleCredential.FromJson(json).CreateScoped(CalendarService.ScopeList.Calendar)`
   - Create event on calendar ID from env `GOOGLE_CALENDAR_ID`
   - Store returned event.Id for future deletion
4. All email + calendar calls enqueued via Hangfire: `BackgroundJob.Enqueue(() => emailService.SendEmailAsync(...))`
5. Retry policies: email 5×/24h; calendar 3× exp backoff (configure in Hangfire server options)
