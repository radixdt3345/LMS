## Implementation Steps
1. Create `SeedService : IHostedService`; inject `LmsDbContext` and `IConfiguration`
2. `SeedUsers`: check if user with email=`SEED_SUPER_ADMIN_EMAIL` exists; if not, create with role=SuperAdmin, is_active=true, password_hash=BCrypt(env `SEED_SUPER_ADMIN_PASSWORD`); same for HR Admin
3. `SeedDepartments`: check if "HR" exists in departments; create if not
4. `SeedLeaveTypes`: check each leave type by name; create if not:
   - Annual Leave: max_days=18, accrual_type=Annual (no carry-forward — org policy)
   - Sick Leave: max_days=10, accrual_type=Annual
   - Casual Leave: max_days=7, accrual_type=Annual
   - Unpaid Leave: max_days=NULL, accrual_type=Unlimited
   - Maternity/Paternity Leave: max_days=90, accrual_type=OneTime
5. Wrap in try-catch; log errors but do not throw (app must start even if seed fails)
6. Register: `builder.Services.AddHostedService<SeedService>()`
