## Implementation Steps
1. Create `axiosClient.ts`: base URL from `VITE_API_BASE_URL` env; attach Bearer token from memory (Redux store); response interceptor: on 401, attempt POST /auth/refresh once (silent), retry original request; on second 401 dispatch logout action
2. Create `authSlice.ts`: state { user, accessToken, refreshToken, isAuthenticated }; actions: setCredentials, logout; tokens stored in Redux state (memory) ONLY — never localStorage
3. Create `LoginPage.tsx`: React Hook Form for email+password; 'Sign in with Microsoft' button calling `useMsal().loginRedirect()`; on submit call POST /auth/login; on success dispatch setCredentials + navigate to /dashboard
4. Create `ProtectedRoute.tsx`: if !isAuthenticated redirect to /login
5. Create `RoleProtectedRoute.tsx`: check user.role against allowedRoles prop; render `<Forbidden403 />` if mismatch
6. Wire routes in `App.tsx`: `/login` → LoginPage; all others wrapped in ProtectedRoute; role-specific pages wrapped in RoleProtectedRoute
7. Configure MSAL React Provider in `main.tsx` with MsalProvider
