## Technical Specification

| `LMS.API/Controllers/AdminController.cs` | Create | GET /admin/users/locked, POST /admin/users/{id}/unlock |

### API Endpoints
| Method | Path | Auth | Request | Response |
|--------|------|------|---------|----------|
| GET | /api/v1/admin/users/locked | Bearer + HRAdmin/SuperAdmin | — | [{ id, email, name, lockout_until, failed_login_count }] |
| POST | /api/v1/admin/users/{id}/unlock | Bearer + HRAdmin/SuperAdmin | — | 204 |

### Key Functions/Methods
| Name | Signature | Responsibility |
|------|-----------|----------------|
| AccountService.LockAccount | `Task LockAccount(Guid userId)` | Set lockout_until = now+30min, called from AuthService on 5th failure |
| AccountService.UnlockAccount | `Task UnlockAccount(Guid userId)` | Clear lockout_until, reset failed_login_count |
| AccountService.GetLockedAccounts | `Task<List<LockedAccountDto>> GetLockedAccounts()` | Return users where lockout_until > now |

## RBAC Context
| Role | Permitted Actions | Enforcement Point |
|------|-------------------|-------------------|
| HR Admin / Super Admin | View locked, unlock | `[Authorize(Policy="HRAdminOrAbove")]` |
| Others | 403 | Policy enforcement |

## Implementation Steps
1. Create `AccountService` with 3 methods above
2. Wire `AccountService.LockAccount` into `AuthService.LoginAsync` (after 5th failure)
3. Create `AdminController` with `[Authorize(Policy="HRAdminOrAbove")]`; GET returns locked accounts; POST calls UnlockAccount
4. Register DI: IAccountService→AccountService
5. Add authorization policy `HRAdminOrAbove` checking JWT role claim
