## RBAC Context
All unauthenticated users may complete SSO callback.

## Implementation Steps
1. Add MSAL config: `AzureAd__TenantId`, `AzureAd__ClientId`, `AzureAd__ClientSecret` from env
2. Implement `SsoCallbackAsync`: use MSAL `IConfidentialClientApplication.AcquireTokenByAuthorizationCode` to exchange code for ID token; extract `oid` (object ID) and `email` claims
3. Upsert logic: find user by azure_ad_oid; if not found, find by email; if still not found, create with role=Employee, is_active=true
4. Issue JWT + refresh token (same as LoginAsync)
5. Register MSAL in DI with `AddMicrosoftIdentityWebApi` or custom IConfidentialClientApplication
