# E-05 — Employee Management
**Feature:** F-05 | **Wave:** 1 | **Domain:** PEOPLE

## Purpose
Full employee lifecycle: create, update, deactivate. Role auto-derived from manager assignment (idempotent). Manager can view direct team. Employees can view/edit their own profile.

## User Stories
| ID | Story |
|----|-------|
| US-05.1 | HR Admin creates and manages employees |
| US-05.2 | Manager views their direct team |
| US-05.3 | Employee views and edits own profile |

## Success Criteria
- Setting manager_id to a user auto-sets their role to Manager (idempotent)
- Deactivated employees cannot login
- employee_code unique (409 on duplicate)
- /team returns only direct reports for the calling Manager
