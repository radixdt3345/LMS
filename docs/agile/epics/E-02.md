# E-02 — Account Lockout Management
**Feature:** F-02 | **Wave:** 1 | **Domain:** AUTH

## Purpose
Protect accounts by locking them after 5 failed login attempts (30-minute lockout). HR Admins and Super Admins can view and manually unlock locked accounts.

## User Stories
| ID | Story |
|----|-------|
| US-02.1 | Auto-lockout after 5 failed login attempts |
| US-02.2 | HR Admin unlocks locked accounts |

## Success Criteria
- 5th failed login triggers 30-min lockout (423 on subsequent attempts)
- locked_until cleared and counter reset on unlock
- Locked accounts list visible only to HR Admin and Super Admin

## Dependencies
- Depends on: E-01 (AUTH-DB-001, AUTH-API-001)
- Blocks: None
