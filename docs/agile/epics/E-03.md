# E-03 — Initial Data Seeding
**Feature:** F-03 | **Wave:** 1 | **Domain:** INFRA

## Purpose
Bootstrap the system on first startup with the minimum viable dataset: 1 SuperAdmin, 1 HR Admin, 1 "HR" department, and 5 leave types. Seeder is idempotent — safe to run on every startup.

## User Stories
| ID | Story |
|----|-------|
| US-03.1 | System bootstrap with seed data on first startup |

## Success Criteria
- Running seeder twice produces no duplicate rows
- All 5 leave types created with correct accrual rules
- Seeded SuperAdmin and HR Admin can login after seed
