# E-09 — Leave Request Workflow
**Feature:** F-09 | **Wave:** 2 | **Domain:** LEAVECORE

## Purpose
Full leave request lifecycle: draft, submit (with sandwich rule computation), cancel (balance restored), revoke by HR Admin. SandwichRuleEngine.ComputeLeaveDays applies within single request range only.

## User Stories
| ID | Story |
|----|-------|
| US-09.1 | Employee submits a leave request with sandwich rule applied |
| US-09.2 | Employee cancels a pending leave request |
| US-09.3 | Employee views personal leave history |
| US-09.4 | HR Admin revokes an approved leave request |

## Success Criteria
- Sandwich rule: non-working day inside the request range is counted (UT-35, UT-36)
- Cross-request isolation: non-working days between TWO separate requests never counted (UT-38)
- Overlapping requests return 409
- Balance check bypassed for Unpaid Leave type (UT-26)
- Retroactive: start_date < today → is_retroactive = true

- Blocks: E-11 (approval engine needs requests)
