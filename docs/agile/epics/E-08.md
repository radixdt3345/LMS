# E-08 — Public Holiday Calendar
**Feature:** F-08 | **Wave:** 1 | **Domain:** LEAVECORE

## Purpose
Maintain the company holiday calendar. HR Admins can add/delete individual holidays or bulk-import via CSV. All authenticated users view the calendar. Holidays are cached (1h TTL) and used by SandwichRuleEngine.

## User Stories
| ID | Story |
|----|-------|
| US-08.1 | Employees view the company holiday calendar |
| US-08.2 | HR Admin adds/deletes holidays and bulk-imports via CSV |

## Success Criteria
- CSV import validates date format; row-level errors shown without blocking valid rows
- Duplicate dates in CSV skipped with warning
- IsHoliday uses cached list (no extra DB call per check)

## Dependencies
- Depends on: E-01, E-03
- Blocks: E-09 (SandwichRuleEngine needs holiday list)
