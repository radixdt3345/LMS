# E-07 — Leave Balance Management
**Feature:** F-07 | **Wave:** 1 | **Domain:** LEAVECORE

## Purpose
Track leave balances per employee per leave type per year. Automate annual credit (Jan 1), proration for new joiners, year-end lapse, and comp-off expiry via Hangfire recurring jobs.

## User Stories
| ID | Story |
|----|-------|
| US-07.1 | Employee views current leave balances |
| US-07.2 | System credits annual leave on Jan 1 and prorates for new joiners |
| US-07.3 | System lapses ALL Annual+OneTime balances at year-end (no carry-forward); expires comp-off credits after 180 days |

## Success Criteria
- Proration formula: (remaining_months/12) × annual_entitlement
- Unpaid Leave zero balance does not block submission (UT-26)
- Hangfire jobs registered with IST-offset UTC cron
- Balance cannot go negative

## Dependencies
- Depends on: E-05 (employees), E-06 (leave types)
- Blocks: E-09 (requests need balance check)
