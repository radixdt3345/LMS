# E-14 — Audit Trail
**Feature:** F-14 | **Wave:** 2 | **Domain:** REPORTING

## Purpose
Immutable append-only audit log of every domain mutation. AuditService.LogAsync wired into all 6 domain services. HR Admin queries log by entity type, entity ID, date range. Delete attempt throws exception.

## User Stories
| ID | Story |
|----|-------|
| US-14.1 | HR Admin views the immutable audit trail with filters |
| US-14.2 | System logs every domain mutation automatically |

## Success Criteria
- AuditService wired in EmployeeService, DepartmentService, LeaveRequestService, CompOffRequestService, ApprovalService, AccountService
- Delete attempt throws InvalidOperationException (UT-56, IT-50)
- Audit log query paginates (max 100/page)

## Dependencies
- Depends on: E-01, E-05 (actors must exist)
- Blocks: E-13 (Super Admin dashboard shows audit events)
