# E-04 — Department Management
**Feature:** F-04 | **Wave:** 1 | **Domain:** PEOPLE

## Purpose
Allow HR Admins to create, edit, and soft-delete organizational departments. Department list is cached in IMemoryCache (1h TTL) and exposed to all authenticated users for form dropdowns.

## User Stories
| ID | Story |
|----|-------|
| US-04.1 | HR Admin manages departments (CRUD + soft-delete) |
| US-04.2 | All users view department list for form dropdowns |

## Success Criteria
- Duplicate department names rejected (409)
- Soft-delete rejected if department has active employees (409)
- Cache invalidated on every mutation
- Employee/Manager role cannot create/edit/delete (403)

## Dependencies
- Depends on: E-03 (INFRA-DB-001 for seed dept)
- Blocks: E-05 (employees need departments)
