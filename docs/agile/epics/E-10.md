# E-10 — Comp-Off Request Workflow
**Feature:** F-10 | **Wave:** 2 | **Domain:** COMPOFF

## Purpose
Employees who work on holidays earn comp-off credits. Workflow: submit request with worked date + hours → Manager approves → credits added to leave_balances. Credits expire after 180 days. Daily Hangfire job handles expiry.

## User Stories
| ID | Story |
|----|-------|
| US-10.1 | Employee submits a comp-off request for a worked holiday |
| US-10.2 | Manager approves or rejects comp-off requests |
| US-10.3 | Employee views comp-off credits and their expiry dates |

## Success Criteria
- worked_hours < 4: validation error
- 4 ≤ hours < 8: 0.5 day credit; ≥ 8: 1 day credit
- Approved comp-off increments leave_balances via LeaveBalanceService
- Expired credits cannot be used
