# E-06 — Leave Types and Policies
**Feature:** F-06 | **Wave:** 1 | **Domain:** LEAVECORE

## Purpose
HR Admins configure the organisation's leave catalog: name, max days per year, carry-forward flag, accrual type (Annual/OneTime/Unlimited), document requirement. The 5 seeded types are the baseline.

## User Stories
| ID | Story |
|----|-------|
| US-06.1 | HR Admin configures leave types and policies |
| US-06.2 | Employees view available leave types |

## Success Criteria
- Cannot delete a leave type with existing balance rows (409)
- Unpaid Leave: max_days_per_year NULL (Unlimited accrual type)
- Cache invalidated on mutation

## Dependencies
- Depends on: E-03 (seeded leave types)
- Blocks: E-07 (balances need leave types), E-09 (requests need types)
