# E-11 — Approval Engine
**Feature:** F-11 | **Wave:** 2 | **Domain:** LEAVECORE

## Purpose
Route leave requests through L1/L2 approval steps. Key routing: if employee has no manager, HR Admin is L1 and L2 is unconditionally skipped (including retroactive). If manager present: L1=Manager, L2=HR Admin only for retroactive or policy-flagged types.

## User Stories
| ID | Story |
|----|-------|
| US-11.1 | Manager approves/rejects leave requests at L1 |
| US-11.2 | HR Admin provides L2 approval when required |
| US-11.3 | HR Admin is sole approver for no-manager employees (L2 always skipped) |

## Success Criteria
- No-manager + retroactive: HR Admin L1 only, L2 unconditionally skipped (UT-53, IT-40)
- Normal retroactive with manager: L1 Manager + L2 HR Admin required
- Balance deducted only on final approval step
- Reject at any step does not deduct balance

## Dependencies
- Depends on: E-09 (requests), E-05 (employees/manager_id)
- Blocks: E-12 (notifications triggered on approval), E-13 (dashboards)
