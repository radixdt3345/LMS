# E-01 — User Authentication
**Feature:** F-01 | **Wave:** 1 | **Domain:** AUTH

## Purpose
Provide secure local email/password login and Azure AD SSO so employees can authenticate. Issue JWT access tokens and refresh tokens to maintain sessions without repeated logins.

## User Stories
| ID | Story |
|----|-------|
| US-01.1 | Azure AD SSO login |
| US-01.2 | Local email/password login |
| US-01.3 | Token refresh and secure logout |

## Success Criteria (from ACs)
- Employee can login via SSO or local credentials
- JWT contains user_id, role, department_id
- Refresh token rotates on use (old revoked)
- Tokens never stored in localStorage
- Rate-limit: 10 login attempts/min per IP (429 on breach)
- CORS blocks unlisted origins

## Dependencies
- Depends on: NONE (foundational)
- Blocks: All other epics (JWT required everywhere)
