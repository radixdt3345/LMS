# US-13.4 — Super Admin Dashboard
**Epic:** E-13 | **Feature:** F-13 | **FRs:** FR-72, FR-75

## User Story
As a Super Admin, I want a dashboard showing system health (Hangfire job status), locked account count, and recent audit events so that I can monitor the system.

## Acceptance Criteria
- [ ] Hangfire job status (last run, next run, failure count) per recurring job
- [ ] Locked accounts count with link to /admin/users/locked
- [ ] Last 10 audit events with actor, action, timestamp
- [ ] Data sourced from /api/v1/dashboard/super-admin

## RBAC
| Role | Access |
|------|--------|
| Super Admin | Full system health |
