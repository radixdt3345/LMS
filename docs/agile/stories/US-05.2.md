# US-05.2 — Manager Views Direct Team
**Epic:** E-05 | **Feature:** F-05 | **FRs:** FR-18, FR-19

## User Story
As a Manager, I want to view my direct team members so that I can manage their leave requests and track availability.

## Acceptance Criteria
- [ ] AC-34: GET /employees/{id}/team returns only direct reports of the calling Manager
- [ ] AC-35: HR Admin can view any employee's team
- [ ] AC-36: Employee cannot call /team (403)

## RBAC
| Role | Access |
|------|--------|
| Manager | Own team only |
| HR Admin / Super Admin | Any team |
| Employee | 403 |
