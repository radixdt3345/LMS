# US-04.1 — HR Admin Manages Departments
**Epic:** E-04 | **Feature:** F-04 | **FRs:** FR-21 to FR-25

## User Story
As an HR Admin, I want to create, edit, and soft-delete departments so that the organisational structure is accurately maintained.

## Acceptance Criteria
- [ ] AC-24: POST /departments creates department; 409 if name already exists
- [ ] AC-25: PUT /departments/{id} updates name/description; 409 on duplicate name
- [ ] AC-26: DELETE /departments/{id} soft-deletes (is_active=false); 409 if active employees assigned
- [ ] AC-27: 403 for Employee/Manager callers on write endpoints

## RBAC
| Role | Access |
|------|--------|
| HR Admin / Super Admin | CRUD |
| Employee / Manager | 403 on writes |
