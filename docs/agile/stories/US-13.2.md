# US-13.2 — Manager Dashboard
**Epic:** E-13 | **Feature:** F-13 | **FRs:** FR-72, FR-74

## User Story
As a Manager, I want a dashboard showing my team's leave calendar, pending approvals count, and headcount on leave today so that I can plan team coverage.

## Acceptance Criteria
- [ ] FullCalendar team leave view (approved leaves for all direct reports)
- [ ] Pending approvals badge (count from /approvals/pending)
- [ ] "On leave today" count
- [ ] Data sourced from /api/v1/dashboard/manager

## RBAC
| Role | Access |
|------|--------|
| Manager | Own team data |
