# US-09.2 — Cancel Pending Leave Request
**Epic:** E-09 | **Feature:** F-09 | **FRs:** FR-47

## User Story
As an Employee, I want to cancel my pending leave request so that my balance is restored and the slot is freed.

## Acceptance Criteria
- [ ] Cancellation allowed for status=Draft or status=Pending only
- [ ] Balance restored on cancellation (if any deducted)
- [ ] Cancelled request status=Cancelled; visible in history

## RBAC
| Role | Access |
|------|--------|
| Employee | Cancel own pending/draft |
