# US-01.2 — Local Email/Password Login
**Epic:** E-01 | **Feature:** F-01 | **FRs:** FR-3, FR-4, FR-7

## User Story
As an employee, I want to sign in with my email address and password so that I can access the system without SSO.

## Acceptance Criteria
- [ ] AC-5: POST /api/v1/auth/login with valid credentials returns JWT + refresh token
- [ ] AC-6: Invalid credentials return 401 (generic message — no user enumeration)
- [ ] AC-7: Locked account returns 423 with lockout_until timestamp
- [ ] AC-8: Rate limit 10/min/IP; 429 on breach

## RBAC
| Role | Access |
|------|--------|
| All | May attempt local login |
