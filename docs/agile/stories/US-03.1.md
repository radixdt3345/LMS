# US-03.1 — System Bootstrap with Seed Data
**Epic:** E-03 | **Feature:** F-03 | **FRs:** FR-28, FR-82, FR-83, FR-84

## User Story
As a system operator, I want the system to bootstrap with a SuperAdmin, HR Admin, default department, and 5 leave types on first startup so that the system is immediately usable.

## Acceptance Criteria
- [ ] AC-19: SeedService runs on startup; idempotent (safe to run multiple times)
- [ ] AC-20: 1 SuperAdmin created with email from SEED_SUPER_ADMIN_EMAIL env var
- [ ] AC-21: 1 HR Admin created with email from SEED_HR_ADMIN_EMAIL env var
- [ ] AC-22: 1 department "HR" created
- [ ] AC-23: 5 leave types: Annual (18d/yr), Sick (10d/yr no-carry), Casual (7d/yr), Unpaid (unlimited), Maternity/Paternity (90d one-time)

## RBAC
| Role | Access |
|------|--------|
| System | Auto-runs on startup |
