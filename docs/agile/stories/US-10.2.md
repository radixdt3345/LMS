# US-10.2 — Approve/Reject Comp-Off Request
**Epic:** E-10 | **Feature:** F-10 | **FRs:** FR-54, FR-55

## User Story
As a Manager, I want to approve or reject comp-off requests from my team so that credits are only awarded for legitimate work.

## Acceptance Criteria
- [ ] Approve: CompOffCreditService.CreditBalance credits leave_balances via LeaveBalanceService
- [ ] Credit formula: 4 ≤ hours < 8 → 0.5 day; hours ≥ 8 → 1 day
- [ ] Reject: no credit issued; notification sent to employee
- [ ] 403 if calling user is not the employee's manager (or HR Admin)

## RBAC
| Role | Access |
|------|--------|
| Manager | Approve/reject team requests |
| HR Admin / Super Admin | Approve/reject any |

- T-048 (COMPOFF-API-001): ApproveRequest + RejectRequest
