# US-14.2 — Immutable Audit Logging
**Epic:** E-14 | **Feature:** F-14 | **FRs:** FR-80, FR-81

## User Story
As the system, I want every domain mutation to be automatically logged to the audit trail so that a complete immutable history exists.

## Acceptance Criteria
- [ ] AuditService.LogAsync called in: EmployeeService, DepartmentService, LeaveRequestService, CompOffRequestService, ApprovalService, AccountService
- [ ] AuditService throws InvalidOperationException on any Update or Delete attempt (UT-56)
- [ ] audit_logs table has no EF update migration; append-only enforced at service level
- [ ] IT-50: delete attempt verified to throw with no DB call made

## RBAC
| Role | Access |
|------|--------|
| System | Write-only (append) |
| No role | Delete (forbidden at all levels) |
