# US-07.1 — Employee Views Leave Balances
**Epic:** E-07 | **Feature:** F-07 | **FRs:** FR-31, FR-32

## User Story
As an Employee, I want to view my current leave balances per type so that I know how many days I have remaining.

## Acceptance Criteria
- [ ] AC-44: GET /leave-balances/me returns balances for current year per leave type
- [ ] AC-45: Unpaid Leave shows "Unlimited" (no numeric balance)
- [ ] AC-46: HR Admin can query GET /leave-balances/{userId} for any employee

## RBAC
| Role | Access |
|------|--------|
| Employee | Own balances |
| Manager | Team balances |
| HR Admin / Super Admin | Any employee |
