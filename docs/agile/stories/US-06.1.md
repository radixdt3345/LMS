# US-06.1 — HR Admin Configures Leave Types
**Epic:** E-06 | **Feature:** F-06 | **FRs:** FR-27 to FR-29

## User Story
As an HR Admin, I want to create and configure leave types with accrual rules so that the leave policy is enforced automatically.

## Acceptance Criteria
- [ ] AC-40: POST /leave-types creates type; 409 on duplicate name
- [ ] AC-41: accrual_type=Unlimited: max_days_per_year may be NULL
- [ ] AC-42: Cannot delete type with existing balance rows (409)

## RBAC
| Role | Access |
|------|--------|
| HR Admin / Super Admin | CRUD |
| Others | 403 on writes |
