# US-13.1 — Employee Dashboard
**Epic:** E-13 | **Feature:** F-13 | **FRs:** FR-72, FR-73

## User Story
As an Employee, I want a dashboard showing my leave balances, upcoming approved leaves, and quick-apply access so that I can manage my leaves from one place.

## Acceptance Criteria
- [ ] Balance cards (one per leave type): allocated, used, remaining
- [ ] Upcoming leave list (next 30 days, status=Approved)
- [ ] Quick-apply button navigates to /leaves/new
- [ ] Data sourced from /api/v1/dashboard/employee

## RBAC
| Role | Access |
|------|--------|
| Employee | Own data |
