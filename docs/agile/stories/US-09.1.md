# US-09.1 — Submit Leave Request with Sandwich Rule
**Epic:** E-09 | **Feature:** F-09 | **FRs:** FR-39 to FR-44, FR-46

## User Story
As an Employee, I want to submit a leave request with a date range, and have the sandwich rule applied automatically so that my balance is correctly computed.

## Acceptance Criteria
- [ ] AC-59: POST /leave-requests creates draft; POST /leave-requests/{id}/submit transitions to Pending
- [ ] AC-60: SandwichRuleEngine.ComputeLeaveDays counts weekends/holidays within the submitted date range (single request scope only — not across requests)
- [ ] AC-61: computed_days saved to leave_request row on submit
- [ ] AC-62: Balance checked on submit; insufficient balance returns 422 (except Unpaid Leave)
- [ ] AC-63: Overlapping date range returns 409
- [ ] AC-64: is_retroactive=true when start_date < today
- [ ] AC-65: Document required if leave_type.requires_document=true; 422 without it

## RBAC
| Role | Access |
|------|--------|
| Employee | Submit own requests |
| Manager | Submit own requests |
