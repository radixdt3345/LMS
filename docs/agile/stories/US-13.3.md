# US-13.3 — HR Admin Dashboard and Reports
**Epic:** E-13 | **Feature:** F-13 | **FRs:** FR-72, FR-75, FR-76

## User Story
As an HR Admin, I want dashboards and reports showing org-wide leave utilization, trends, and compliance with CSV export so that I can make informed workforce decisions.

## Acceptance Criteria
- [ ] Department-wise utilization bar chart (Chart.js)
- [ ] Compliance gauge: % employees who submitted leave plan
- [ ] GET /reports/export?type=utilization streams CSV (Content-Type: text/csv, no memory buffering)
- [ ] Data sourced from /api/v1/dashboard/hr

## RBAC
| Role | Access |
|------|--------|
| HR Admin / Super Admin | Full reporting access |

## Tasks
- T-070 (REPORTING-API-001): GET /dashboard/hr + report endpoints
- T-073 (REPORTING-UI-003): HR Admin dashboard
