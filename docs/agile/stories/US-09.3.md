# US-09.3 — View Personal Leave History
**Epic:** E-09 | **Feature:** F-09 | **FRs:** FR-45

## User Story
As an Employee, I want to view my complete leave request history with statuses so that I can track my usage and plan future leaves.

## Acceptance Criteria
- [ ] GET /leave-requests?employee_id=me returns paginated history with status, dates, computed_days
- [ ] All statuses visible: Draft, Pending, Approved, Rejected, Cancelled, Revoked

## RBAC
| Role | Access |
|------|--------|
| Employee / Manager | Own history |
| HR Admin | Any employee history |
