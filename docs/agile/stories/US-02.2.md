# US-02.2 — HR Admin Unlocks Accounts
**Epic:** E-02 | **Feature:** F-02 | **FRs:** FR-8

## User Story
As an HR Admin, I want to view locked accounts and manually unlock them so that legitimate users can regain access quickly.

## Acceptance Criteria
- [ ] AC-16: GET /admin/users/locked returns all currently locked users (HR Admin / Super Admin only)
- [ ] AC-17: POST /admin/users/{id}/unlock clears lockout_until and resets counter
- [ ] AC-18: 403 for Employee or Manager callers

## RBAC
| Role | Access |
|------|--------|
| HR Admin | View + unlock |
| Super Admin | View + unlock |
| Employee/Manager | 403 |

## Tasks
- T-009 (AUTH-API-004): UnlockAccount + GetLockedAccounts
- T-010 (AUTH-UI-002): Locked accounts page
