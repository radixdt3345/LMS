# US-01.3 — Token Refresh and Secure Logout
**Epic:** E-01 | **Feature:** F-01 | **FRs:** FR-5, FR-6, FR-11

## User Story
As an authenticated user, I want my session to refresh silently so that I'm not logged out mid-session, and I want logout to invalidate my tokens.

## Acceptance Criteria
- [ ] AC-9: POST /auth/refresh with valid refresh token returns new access + refresh token (old revoked)
- [ ] AC-10: POST /auth/logout revokes current refresh token
- [ ] AC-11: Expired/revoked refresh token returns 401
- [ ] AC-12: Frontend intercepts 401, attempts silent refresh once, then redirects to login

## RBAC
| Role | Access |
|------|--------|
| Authenticated | May refresh/logout |
