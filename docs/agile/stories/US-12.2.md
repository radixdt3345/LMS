# US-12.2 — Email Notifications via SendGrid
**Epic:** E-12 | **Feature:** F-12 | **FRs:** FR-69, FR-70

## User Story
As an Employee, I want to receive an email when my leave is approved or rejected so that I have a record outside the application.

## Acceptance Criteria
- [ ] EmailService.SendEmailAsync: uses SendGrid v3 HTTP API; body constructed as plain text + inline HTML in C# string
- [ ] NO SendGrid template IDs, NO dynamic templates, NO templateId config key
- [ ] Email queued via Hangfire; retries 5 times over 24 hours on failure
- [ ] UT-54 asserts no templateId property in the SendGrid API call

## RBAC
