# US-11.2 — L2 Approval (HR Admin)
**Epic:** E-11 | **Feature:** F-11 | **FRs:** FR-60, FR-61

## User Story
As an HR Admin, I want to provide L2 approval for retroactive leave requests (or policy-flagged types) so that higher-risk leaves have dual sign-off.

## Acceptance Criteria
- [ ] L2 triggered when: leave_type.requires_l2=true OR is_retroactive=true AND employee has a manager
- [ ] L2 NOT triggered when: employee has no manager (HR Admin already L1 — no L2 ever)
- [ ] On L2 approve: status=Approved, balance deducted, employee notified
- [ ] On L2 reject: status=Rejected, L1 approval reverted (no balance change)

## RBAC
| Role | Access |
|------|--------|
| HR Admin / Super Admin | L2 approval |
