# US-01.1 — Azure AD SSO Login
**Epic:** E-01 | **Feature:** F-01 | **FRs:** FR-1, FR-2

## User Story
As an employee, I want to sign in with my Microsoft account (Azure AD SSO) so that I don't need a separate password.

## Acceptance Criteria
- [ ] AC-1: 'Sign in with Microsoft' button initiates MSAL redirect
- [ ] AC-2: Successful MSAL callback creates/upserts user by azure_ad_oid, issues JWT + refresh token
- [ ] AC-3: New users auto-created with role=Employee
- [ ] AC-4: Redirect lands user on role-appropriate dashboard

## RBAC
| Role | Access |
|------|--------|
| All | May initiate SSO login |
