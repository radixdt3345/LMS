# US-10.3 — View Comp-Off Credits and Expiry
**Epic:** E-10 | **Feature:** F-10 | **FRs:** FR-56, FR-57

## User Story
As an Employee, I want to view my comp-off credits and their expiry dates so that I can use them before they lapse.

## Acceptance Criteria
- [ ] GET /comp-off/credits/me returns credits with expires_at
- [ ] Expiry warning shown in UI when expires_at < now + 30 days
- [ ] Expired credits shown but not usable

## RBAC
| Role | Access |
|------|--------|
| Employee / Manager | Own credits |
| HR Admin | Any employee |
