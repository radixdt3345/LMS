# US-07.3 — Year-End Lapse and Comp-Off Expiry
**Epic:** E-07 | **Feature:** F-07 | **FRs:** FR-36, FR-37, FR-38

## User Story
As the system, I want to zero out all Annual and OneTime leave balances at year-end (no carry-forward is org policy) and expire comp-off credits after 180 days so that unused leave doesn't accumulate incorrectly.

## Acceptance Criteria
- [ ] AC-50: YearEndLapseJob: zeroes remaining balance for all Annual and OneTime leave types (org policy: no carry-forward for any leave type)
- [ ] AC-51: CompOffExpiryJob: daily at midnight IST; marks comp-off credit rows where expires_at < today as used
- [ ] AC-52: Hangfire job failures retry (email: 5×/24h; calendar: 3× exp backoff; balance jobs: 3×)
