# US-08.2 — HR Admin Manages Holidays
**Epic:** E-08 | **Feature:** F-08 | **FRs:** FR-63, FR-64, FR-65

## User Story
As an HR Admin, I want to add, delete, and bulk-import holidays via CSV so that the calendar stays up to date with minimal manual effort.

## Acceptance Criteria
- [ ] AC-55: POST /holidays creates a holiday; 409 on duplicate date
- [ ] AC-56: POST /holidays/bulk-import accepts CSV (columns: date YYYY-MM-DD, name, is_optional); validates each row; returns row-level errors for invalid rows without blocking valid ones
- [ ] AC-57: DELETE /holidays/{id} removes the holiday; cache invalidated
- [ ] AC-58: Duplicate dates in CSV skipped with warning (not error)

## RBAC
| Role | Access |
|------|--------|
| HR Admin / Super Admin | Create, delete, bulk-import |
| Others | 403 on writes |
