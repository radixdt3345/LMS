# US-02.1 — Auto-Lockout After Failed Attempts
**Epic:** E-02 | **Feature:** F-02 | **FRs:** FR-7

## User Story
As the system, I want to lock an account after 5 consecutive failed login attempts (30-minute lockout) so that brute-force attacks are prevented.

## Acceptance Criteria
- [ ] AC-13: 5th failed attempt sets lockout_until = now + 30min, returns 423
- [ ] AC-14: Successful login resets failed_login_count to 0
- [ ] AC-15: Login attempt during lockout returns 423 with remaining lockout time

## RBAC
| Role | Access |
|------|--------|
| System | Triggered automatically |
