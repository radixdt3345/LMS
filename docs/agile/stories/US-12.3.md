# US-12.3 — Google Calendar Event on Leave Approval
**Epic:** E-12 | **Feature:** F-12 | **FRs:** FR-71

## User Story
As an Employee, I want an event created on the company Google Calendar when my leave is approved so that my absence is visible to the whole team.

## Acceptance Criteria
- [ ] CalendarService.CreateLeaveEvent: uses Google Calendar API v3 with service account JSON key from env var GOOGLE_CALENDAR_SERVICE_ACCOUNT_JSON
- [ ] Events created on shared company calendar (calendarId from env GOOGLE_CALENDAR_ID)
- [ ] NO per-user OAuth2 consent or redirect flow
- [ ] Event deleted on revoke/cancel
- [ ] Queued via Hangfire; 3 retries with exponential backoff
- [ ] IT-44 verifies service account flow; UT-55 verifies no per-user consent code path

## RBAC
| Role | Access |
|------|--------|
| System | Triggered on final approval |
