# US-14.1 — View Audit Trail
**Epic:** E-14 | **Feature:** F-14 | **FRs:** FR-77 to FR-79

## User Story
As an HR Admin, I want to view the audit trail of all system actions with filters so that I can investigate changes and ensure compliance.

## Acceptance Criteria
- [ ] GET /audit-logs?entity_type=&entity_id=&from=&to= returns paginated audit log (max 100/page)
- [ ] Diff viewer shows old/new value JSON diff per entry
- [ ] Filters: entity type, date range, actor (user)
- [ ] No delete button visible for any role

## RBAC
| Role | Access |
|------|--------|
| HR Admin / Super Admin | Read-only audit log |
| Others | 403 |
