# US-09.4 — HR Admin Revokes Approved Leave
**Epic:** E-09 | **Feature:** F-09 | **FRs:** FR-48, FR-50

## User Story
As an HR Admin, I want to revoke an approved leave request so that errors can be corrected and balances restored.

## Acceptance Criteria
- [ ] POST /leave-requests/{id}/revoke (HR Admin only) transitions status to Revoked
- [ ] Balance restored on revoke
- [ ] Google Calendar event deleted on revoke (async via Hangfire)
- [ ] Notification sent to employee on revoke

## RBAC
| Role | Access |
|------|--------|
| HR Admin / Super Admin | Revoke any approved request |
