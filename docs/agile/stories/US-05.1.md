# US-05.1 — HR Admin Creates and Manages Employees
**Epic:** E-05 | **Feature:** F-05 | **FRs:** FR-12 to FR-17

## User Story
As an HR Admin, I want to create, edit, and deactivate employees so that the workforce is accurately represented in the system.

## Acceptance Criteria
- [ ] AC-30: POST /employees creates employee with unique employee_code; 409 on duplicate
- [ ] AC-31: Role auto-derived: if employee has direct reports, role=Manager (idempotent)
- [ ] AC-32: DELETE /employees/{id} soft-deactivates; deactivated user cannot login (401)
- [ ] AC-33: manager_id nullable (no-manager employees allowed)

## RBAC
| Role | Access |
|------|--------|
| HR Admin / Super Admin | Full CRUD |
| Others | 403 on writes |
