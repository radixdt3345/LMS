# US-11.3 — No-Manager Routing (HR Admin as Sole Approver)
**Epic:** E-11 | **Feature:** F-11 | **FRs:** FR-58, FR-61

## User Story
As an HR Admin, I want to be the sole approver for employees who have no manager assigned, and I want L2 to always be skipped for such employees, so that no request is blocked waiting for a non-existent manager.

## Acceptance Criteria
- [ ] employee.manager_id IS NULL → HR Admin is L1; L2 unconditionally skipped
- [ ] This applies even if the request is retroactive (no-manager rule overrides retroactive L2 trigger)
- [ ] UT-53 and IT-40 explicitly verify this behaviour

## RBAC
| Role | Access |
|------|--------|
| HR Admin / Super Admin | Sole approver for no-manager employees |
