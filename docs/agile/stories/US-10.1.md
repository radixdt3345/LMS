# US-10.1 — Submit Comp-Off Request
**Epic:** E-10 | **Feature:** F-10 | **FRs:** FR-51 to FR-53

## User Story
As an Employee, I want to submit a comp-off request for a day I worked on a public holiday so that I earn additional leave credit.

## Acceptance Criteria
- [ ] POST /comp-off/requests submits request with worked_date and worked_hours
- [ ] worked_hours < 4: validation error 422
- [ ] worked_date must be a past holiday (HolidayService.IsHoliday = true)
- [ ] Duplicate request for same worked_date: 409

## RBAC
| Role | Access |
|------|--------|
| Employee / Manager | Submit own comp-off |
