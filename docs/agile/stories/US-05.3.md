# US-05.3 — Employee Views and Edits Own Profile
**Epic:** E-05 | **Feature:** F-05 | **FRs:** FR-20

## User Story
As an Employee, I want to view and edit my own profile (name, phone, etc.) so that my information is current.

## Acceptance Criteria
- [ ] AC-37: GET /employees/me returns own profile
- [ ] AC-38: PUT /employees/me allows editing first_name, last_name, phone (not role, department_id, employee_code)
- [ ] AC-39: Role field is read-only for self-edit

## RBAC
| Role | Access |
|------|--------|
| All authenticated | Own profile read/edit (limited fields) |
