# US-11.1 — L1 Approval (Manager)
**Epic:** E-11 | **Feature:** F-11 | **FRs:** FR-58, FR-59

## User Story
As a Manager, I want to approve or reject leave requests from my direct reports at L1 so that the approval chain progresses.

## Acceptance Criteria
- [ ] POST /approvals/{id}/approve (L1 step) by Manager; creates approval_step row
- [ ] If no L2 required: balance deducted, status=Approved, notification sent
- [ ] If L2 required: status stays Pending, HR Admin notified for L2
- [ ] POST /approvals/{id}/reject: status=Rejected, no balance change, employee notified

## RBAC
| Role | Access |
|------|--------|
| Manager | L1 for direct reports |
| HR Admin | L1 when employee has no manager |
