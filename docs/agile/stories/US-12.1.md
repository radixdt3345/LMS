# US-12.1 — In-App Notifications
**Epic:** E-12 | **Feature:** F-12 | **FRs:** FR-66, FR-67, FR-68

## User Story
As an Employee, I want to receive in-app notifications when my leave status changes so that I'm always informed within the application.

## Acceptance Criteria
- [ ] NotificationService.CreateNotification inserts row in notifications table
- [ ] GET /notifications/unread-count polled every 60s by frontend (Axios)
- [ ] Bell badge shows count; dropdown shows last 10 notifications
- [ ] POST /notifications/{id}/read marks as read; count decrements

## RBAC
| Role | Access |
|------|--------|
| All authenticated | Own notifications |
